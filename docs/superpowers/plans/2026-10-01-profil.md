# Profil (Phase 3) — plan d'implémentation

> **Pour les agents :** SOUS-SKILL REQUISE : utiliser `superpowers:subagent-driven-development`
> (recommandé) ou `superpowers:executing-plans` pour dérouler ce plan tâche par tâche. Les étapes
> sont en cases à cocher (`- [ ]`).

**But :** l'utilisateur dépose son CV, le service en tire un profil structuré par DeepSeek,
l'utilisateur le corrige et choisit ses préférences — et peut supprimer toutes ses données.

**Architecture :** le dépôt refuse tout ce qui peut l'être **avant de payer un token** (taille,
type réel, plafond journalier, absence de texte), puis lance l'analyse en arrière-plan dans le
process `api` et rend la main. L'état vit dans `profiles` ; une photo, qui n'a pas de texte à
extraire localement, transite par Redis avec un TTL court et ne touche jamais le disque.

**Stack :** Python 3.11+, FastAPI, SQLAlchemy 2.0 async, Alembic, Redis, SDK `openai` pointé sur
DeepSeek, `pdfplumber`, `python-docx`. Côté web : Next 16 + React 19, Server Components, zéro
composant client.

**Spec :** `docs/superpowers/specs/2026-10-01-profil-design.md` — à lire en entier avant de
commencer. Ce plan argumente depuis elle.

## Contraintes globales

Elles s'appliquent à **toutes** les tâches, sans être répétées dans chacune.

- **Aucune dépendance hors de `openai`, `pdfplumber`, `python-docx`.** Le §3 du CLAUDE.md exige une
  justification écrite par ajout. Pas de bibliothèque d'images, pas d'OCR, pas de poppler.
- **Le texte d'un CV ne doit JAMAIS atteindre un journal, un message d'exception ou une alerte
  admin.** C'est la règle n°1 de cette phase. Le dépôt porte `tests/test_logs_sans_pii.py` et
  `tests/test_logs_sans_pii_uvicorn_reel.py`.
- **Aucun composant client** (`'use client'`) côté web. Les écrans fonctionnent sans JavaScript.
- **Aucun texte utilisateur hors de `web/app/textes.ts`.** Vouvoiement, français simple, aucun
  jargon RH.
- **L'API ne renvoie jamais de phrase** : `{"erreur": "<code>"}`. Les textes vivent chez le client.
- Type hints partout, `mypy --strict src` vert. Aucun `print()` — `structlog` uniquement.
- Commentaires et docstrings **en français**, qui disent **pourquoi** et pas quoi.
- **La base de développement est partagée** et porte des offres réelles. Jamais de
  `docker compose down -v`, jamais d'`alembic downgrade`.
- Les tests d'intégration exigent **`-m integration` EN PLUS de `RUN_INTEGRATION_TESTS=1`** ; sans
  le marqueur, pytest ne collecte rien et **sort en succès trompeur**.
- Python : `/home/mamadbah/projects/jobbot/.venv/bin/python -m pytest`, `.../bin/mypy`,
  `.../bin/ruff`.
- Commits en français, format `feat(portee): sujet`, terminés par les deux lignes d'attribution en
  vigueur dans le dépôt.

## Review Focus

Cinq classes d'entrée que la spec implique sans qu'aucune tâche ne les exerce spontanément, et qui
mordraient un vrai utilisateur. Chacune reçoit son test dans la tâche qui porte le code.

1. **Un PDF chiffré ou tronqué** (`%PDF` en tête, corps inexploitable) : `pdfplumber` lève, et
   l'utilisateur doit lire un refus clair, pas récolter un 500. → **Tâche 3**
2. **Un ZIP qui n'est pas un DOCX** (un `.jar`, un dossier compressé) : un DOCX *est* un ZIP, donc
   les octets de tête ne prouvent rien. L'ouverture doit échouer proprement. → **Tâche 3**
3. **Un CV rédigé en anglais** : courant au Sénégal pour les postes ONG et international, que le
   §7 du brief cite comme un gisement. Il doit être analysé, pas refusé ni massacré. → **Tâche 5**
4. **Un JSON bien formé mais de mauvaise forme** (clés manquantes, `experiences` en chaîne au lieu
   de liste) : il ne doit jamais entrer dans `structured`, que la Phase 5 traitera comme source de
   vérité du post-contrôle anti-invention (§8.5). → **Tâche 5**
5. **Deux dépôts simultanés du même utilisateur** : deux tâches de fond écrivant la même ligne
   `profiles`, dont la plus lente écrase la plus récente. → **Tâche 6**

resterait vide à jamais. Elle n'a jamais été écrite par aucun code, donc la
supprimer ne perd aucune donnée — vérifié avant d'écrire cette migration.

Revision ID: a1c2e3f40006
Revises: a1c2e3f40005
"""

from __future__ import annotations

import sqlalchemy as sa
from alembic import op

revision: str = "a1c2e3f40006"
down_revision: str | None = "a1c2e3f40005"
branch_labels: str | None = None
depends_on: str | None = None


def upgrade() -> None:
    # server_default sur l'ajout : les lignes existantes doivent recevoir une
    # valeur, sinon la colonne NOT NULL échoue sur une table non vide.
    op.add_column(
        "profiles",
        sa.Column(
            "parse_etat",
            sa.String(16),
            nullable=False,
            server_default="en_attente",
        ),
    )
    op.add_column("profiles", sa.Column("parse_erreur", sa.String(64), nullable=True))
    op.add_column(
        "profiles",
        sa.Column("parse_demarre_le", sa.DateTime(timezone=True), nullable=True),
    )
    op.create_check_constraint(
        "ck_profiles_parse_etat",
        "profiles",
        "parse_etat IN ('en_attente', 'en_cours', 'pret', 'echec')",
    )
    op.drop_column("profiles", "cv_file_path")


def downgrade() -> None:
    op.add_column("profiles", sa.Column("cv_file_path", sa.String(512), nullable=True))
    op.drop_constraint("ck_profiles_parse_etat", "profiles", type_="check")
    op.drop_column("profiles", "parse_demarre_le")
    op.drop_column("profiles", "parse_erreur")
    op.drop_column("profiles", "parse_etat")
```

- [ ] **Step 7 : Écrire la règle de péremption, en pur**

C'est ce qui remplace un balayeur de tâches zombies. La logique est une décision, pas une requête :
elle vit dans `core`, se teste sans base et sans horloge truquée.

Créer `src/core/cv_etat.py` :

```python
"""Ce que l'écran doit montrer, à partir de ce que la base dit.

Si `api` redémarre en pleine analyse, rien ne reprend le travail : le profil
reste `en_cours` pour toujours. Plutôt qu'un balayeur de tâches zombies — un
processus de plus à faire tourner, à surveiller et à déboguer un jour de panne —
l'écran traite une analyse trop vieille comme un échec et propose de redéposer.

Fonction PURE, horloge injectée : la règle se teste sans base et sans attendre.
"""

from __future__ import annotations

from datetime import datetime

ANALYSE_INTERROMPUE = "analyse_interrompue"


def etat_affiche(
    parse_etat: str,
    parse_demarre_le: datetime | None,
    *,
    maintenant: datetime,
    delai_max_secondes: int,
) -> tuple[str, str | None]:
    """Rend `(état, code d'erreur)` tels que le client doit les voir."""
    if parse_etat != "en_cours":
        return parse_etat, None
    if parse_demarre_le is None:
        # `en_cours` sans date de départ : incohérent, donc suspect. On préfère
        # proposer de redéposer plutôt que de faire attendre indéfiniment.
        return "echec", ANALYSE_INTERROMPUE
    age = (maintenant - parse_demarre_le).total_seconds()
    if age > delai_max_secondes:
        return "echec", ANALYSE_INTERROMPUE
    return "en_cours", None
```

```python
"""Reconnaissance du type réel d'un fichier et extraction de son texte.

Module PUR : aucun réseau, aucune base, aucun framework. C'est lui qui porte le
filtre le plus rentable du produit — tout ce qui peut être refusé l'est ici,
**avant qu'un seul token soit payé** à DeepSeek.

Le type est déduit des octets de tête et jamais de l'extension : un fichier
renommé ne prouve rien. Et un DOCX *étant* une archive ZIP, même les octets de
tête ne suffisent pas à l'affirmer — d'où la distinction entre `CvTypeRefuse`
(les octets de tête disent non) et `CvIllisible` (ils disaient oui, mais le
corps est inexploitable : PDF chiffré, archive tronquée, ZIP sans document).
"""

from __future__ import annotations

import io
import zipfile
from collections.abc import Callable
from dataclasses import dataclass
from typing import Literal

from src.core.erreurs import CvIllisible, CvSansTexte, CvTypeRefuse

TypeCv = Literal["pdf", "docx", "jpeg", "png"]

_SIGNATURES: tuple[tuple[bytes, TypeCv], ...] = (
    (b"%PDF", "pdf"),
    (b"\xff\xd8\xff", "jpeg"),
    (b"\x89PNG\r\n\x1a\n", "png"),
    # En dernier : une archive ZIP *peut* être un DOCX, mais aussi n'importe
    # quoi d'autre. C'est `extraire_texte` qui tranche.
    (b"PK\x03\x04", "docx"),
)


def reconnaitre_type(contenu: bytes) -> TypeCv:
    for signature, type_cv in _SIGNATURES:
        if contenu.startswith(signature):
            return type_cv
    raise CvTypeRefuse


def est_une_image(type_cv: TypeCv) -> bool:
    """Une image n'a pas de texte à extraire localement : elle part telle quelle
    au modèle multimodal (spec §8)."""
    return type_cv in ("jpeg", "png")


def _lire_pdf(contenu: bytes) -> str:
    import pdfplumber

    with pdfplumber.open(io.BytesIO(contenu)) as document:
        return "\n".join(page.extract_text() or "" for page in document.pages)


def _lire_docx(contenu: bytes) -> str:
    from docx import Document

    document = Document(io.BytesIO(contenu))
    return "\n".join(p.text for p in document.paragraphs)


@dataclass(frozen=True, slots=True)
class Lecteurs:
    """Lecteurs injectables.

    Les chemins d'échec (PDF chiffré, archive tronquée) se testent en injectant
    un lecteur qui lève, plutôt qu'en fabriquant et maintenant des fichiers
    corrompus dans le dépôt.
    """

    pdf: Callable[[bytes], str]
    docx: Callable[[bytes], str]


LECTEURS_REELS = Lecteurs(pdf=_lire_pdf, docx=_lire_docx)


def extraire_texte(
    contenu: bytes,
    type_cv: TypeCv,
    *,
    minimum: int,
    lecteurs: Lecteurs | None = None,
) -> str:
    """Rend le texte du document, ou lève.

    `minimum` compte les caractères **hors espaces** : un PDF scanné rend
    rarement zéro caractère, il rend quelques artefacts de police. « Vide » ne
    serait donc pas un test suffisant.
    """
    if est_une_image(type_cv):  # pragma: no cover — l'appelant ne doit pas le faire
        raise CvIllisible

    lecteurs = lecteurs or LECTEURS_REELS
    lecteur = lecteurs.pdf if type_cv == "pdf" else lecteurs.docx

    try:
        texte = lecteur(contenu)
    except (CvSansTexte, CvIllisible):
        raise
    except (zipfile.BadZipFile, KeyError, ValueError, OSError) as exc:
        # `raise ... from None` et AUCUN détail recopié : le message d'une
        # bibliothèque de lecture peut contenir un fragment du document, et une
        # alerte admin recopie tout son contexte par le réseau (§7).
        raise CvIllisible from None
    except Exception:
        # Une bibliothèque de lecture peut lever n'importe quoi sur un fichier
        # malformé. Un 500 ici serait une porte ouverte : tout échec de lecture
        # est un refus de lecture, pas une panne du service.
        raise CvIllisible from None

    if len(texte.replace(" ", "").strip()) < minimum:
        raise CvSansTexte
    return texte
```

> `except Exception` est large, et c'est voulu : `pdfplumber` et `python-docx` lèvent des types
> variés et non documentés sur un fichier malformé. Le laisser remonter transformerait un fichier
> cassé en panne de service. La variable `exc` n'est pas utilisée **exprès** — la relire mettrait
> du contenu de document dans l'exception.

    en clair (§14.4). Tronquée à 32 caractères — une clé Redis n'a pas besoin
    des 64 du digest complet, et la collision reste hors d'atteinte."""

def fenetre_heure() -> str:
    # Fenêtre fixe, pas glissante : une requête à 12:59:59 et une à 13:00:01
    # tombent dans deux fenêtres différentes, ce qui autorise jusqu'au double du

```python
"""Client DeepSeek unique. Aucun appel au LLM ailleurs dans le dépôt (§9).

Tarifs et noms de modèles **relevés le 2026-10-01** contre l'API officielle, pas
recopiés du brief : le §9 nommait `deepseek-chat`, qui n'existe plus. Ces valeurs
sont datées et se revérifient.
"""

from __future__ import annotations

import asyncio
from dataclasses import dataclass
from datetime import UTC, datetime
from decimal import Decimal

from src.core.erreurs import AnalyseIndisponible
from src.logging_setup import get_logger

log = get_logger(__name__)

# Dollars par million de tokens, hors pointe. La pointe double ces valeurs.
_TARIFS: dict[str, tuple[Decimal, Decimal, Decimal]] = {
    # modèle: (entrée servie par le cache, entrée fraîche, sortie)
    "deepseek-flash": (Decimal("0.003"), Decimal("0.15"), Decimal("0.6")),
    "deepseek-v4-pro": (Decimal("0.022"), Decimal("0.66"), Decimal("1.98")),
}

_MILLION = Decimal(1_000_000)
# 01:00-04:00 et 06:00-10:00 UTC, du lundi au vendredi.
_HEURES_DE_POINTE = frozenset({1, 2, 3, 6, 7, 8, 9})


def est_en_pointe(moment: datetime) -> bool:
    """Le week-end n'est jamais en pointe : ne regarder que l'heure
    surfacturerait tous les samedis et dimanches du double."""
    return moment.weekday() < 5 and moment.hour in _HEURES_DE_POINTE


@dataclass(frozen=True, slots=True)
class CoutAppel:
    tokens_entree_cache: int
    tokens_entree_frais: int
    tokens_sortie: int
    cout_usd: Decimal


def calculer_cout(
    modele: str,
    tokens_entree_cache: int,
    tokens_entree_frais: int,
    tokens_sortie: int,
    *,
    moment: datetime | None = None,
) -> Decimal:
    """Coût en dollars d'un appel.

    `moment` est injectable pour que le test puisse se placer en pointe ou en
    heure creuse sans attendre la bonne heure.
    """
    if modele not in _TARIFS:
        # Facturer 0 un modèle inconnu ferait croire que le produit ne coûte
        # rien : l'erreur qu'on ne verrait jamais dans un tableau de bord.
        raise ValueError(f"tarif inconnu pour le modèle {modele!r}")

    tarif_cache, tarif_frais, tarif_sortie = _TARIFS[modele]
    facteur = Decimal(2) if est_en_pointe(moment or datetime.now(UTC)) else Decimal(1)
    return (
        (Decimal(tokens_entree_cache) * tarif_cache
         + Decimal(tokens_entree_frais) * tarif_frais
         + Decimal(tokens_sortie) * tarif_sortie)
        / _MILLION
        * facteur
    )
```

À la suite du même fichier :

```python
_RELANCES = 3
_ATTENTE_INITIALE_S = 1.0
_DELAI_MAX_S = 60.0


async def appeler_deepseek(
    messages: list[dict[str, object]],
    *,
    modele: str,
    cle_api: str,
    temperature: float,
) -> tuple[str, CoutAppel]:
    """Un appel, avec relance exponentielle sur 429 et 5xx (§9).

    Rend le texte de la réponse et le coût. Lève `AnalyseIndisponible` quand
    DeepSeek reste injoignable : l'appelant doit alors NE PAS décompter le quota.

    Aucun fragment de message n'est journalisé : les messages portent le CV.
    """
    from openai import AsyncOpenAI
    from openai import APIStatusError, APITimeoutError, APIConnectionError

    client = AsyncOpenAI(
        api_key=cle_api, base_url="https://api.deepseek.com", timeout=_DELAI_MAX_S
    )
    attente = _ATTENTE_INITIALE_S
    for tentative in range(1, _RELANCES + 1):
        try:
            reponse = await client.chat.completions.create(
                model=modele,
                messages=messages,  # type: ignore[arg-type]
                temperature=temperature,
            )
        except (APITimeoutError, APIConnectionError) as exc:
            motif = type(exc).__name__
        except APIStatusError as exc:
            if exc.status_code not in (429,) and exc.status_code < 500:
                # 4xx autre que 429 : la requête est fautive, relancer
                # à l'identique ne changera rien et coûterait du temps.
                log.error("deepseek_requete_refusee", statut=exc.status_code)
                raise AnalyseIndisponible from None
            motif = f"http_{exc.status_code}"
        else:
            usage = reponse.usage
            cout = CoutAppel(
                tokens_entree_cache=getattr(usage, "prompt_cache_hit_tokens", 0) or 0,
                tokens_entree_frais=getattr(usage, "prompt_cache_miss_tokens", 0)
                or (usage.prompt_tokens if usage else 0),
                tokens_sortie=usage.completion_tokens if usage else 0,
                cout_usd=Decimal(0),
            )
            cout = CoutAppel(
                cout.tokens_entree_cache,
                cout.tokens_entree_frais,
                cout.tokens_sortie,
                calculer_cout(
                    modele,
                    cout.tokens_entree_cache,
                    cout.tokens_entree_frais,
                    cout.tokens_sortie,
                ),
            )
            return (reponse.choices[0].message.content or ""), cout

        log.warning("deepseek_relance", tentative=tentative, motif=motif)
        if tentative < _RELANCES:
            await asyncio.sleep(attente)
            attente *= 2

    log.error("deepseek_injoignable", relances=_RELANCES)
    raise AnalyseIndisponible from None
```

> `getattr(usage, "prompt_cache_hit_tokens", 0)` plutôt qu'un accès direct : ces champs sont
> propres à DeepSeek et absents des types du SDK `openai`. Le repli sur `prompt_tokens` garantit
> qu'on ne compte jamais **zéro** entrée — ce qui ferait croire à un coût nul.

```python
"""CV brut (texte ou image) → profil structuré + transcription.

Les deux chemins convergent : après analyse, une photo et un PDF ont rempli
exactement les mêmes colonnes. Rien dans la suite du produit n'a besoin de savoir
par où le profil est arrivé (spec §8).
"""

from __future__ import annotations

import base64
import json
from collections.abc import Awaitable, Callable
from typing import Any

from src.core.erreurs import CvIllisible
from src.llm.client import CoutAppel
from src.llm.prompts import PROMPT_CV, VERSION_PROMPT_CV
from src.logging_setup import get_logger

log = get_logger(__name__)

__all__ = ["VERSION_PROMPT_CV", "analyser_cv"]

Appelant = Callable[..., Awaitable[tuple[str, CoutAppel]]]

# La forme que la Phase 5 traitera comme source de vérité (§8.5). Un JSON
# syntaxiquement valide mais de mauvaise forme ne doit pas entrer en base : le
# post-contrôle anti-invention échouerait plus tard, loin de sa cause.
_LISTES = ("experiences", "formations", "competences", "langues", "secteurs_vises")
_CHAINES_OPTIONNELLES = (
    "nom_complet", "titre", "telephone", "mobilite", "pretention_salariale",
)


def _nettoyer(brut: str) -> str:
    """Retire les clôtures de code dont le modèle entoure souvent son JSON (§9)."""
    texte = brut.strip()
    if texte.startswith("```"):
        texte = texte.split("\n", 1)[-1] if "\n" in texte else ""
        if texte.rstrip().endswith("```"):
            texte = texte.rstrip()[: -len("```")]
    return texte.strip()


def _valider(donnees: Any) -> dict[str, Any]:
    if not isinstance(donnees, dict):
        raise CvIllisible
    for cle in _LISTES:
        if not isinstance(donnees.get(cle), list):
            raise CvIllisible
    for cle in _CHAINES_OPTIONNELLES:
        if cle not in donnees:
            raise CvIllisible
        if donnees[cle] is not None and not isinstance(donnees[cle], str):
            raise CvIllisible
    if not isinstance(donnees.get("transcription"), str):
        raise CvIllisible
    return donnees


def _messages(texte: str | None, image: bytes | None, type_image: str | None) -> list[dict[str, Any]]:
    if image is not None:
        encodee = base64.b64encode(image).decode("ascii")
        contenu: list[dict[str, Any]] = [
            {"type": "text", "text": "Analyse ce CV."},
            {
                "type": "image_url",
                "image_url": {"url": f"data:image/{type_image};base64,{encodee}"},
            },
        ]
        return [{"role": "system", "content": PROMPT_CV}, {"role": "user", "content": contenu}]
    return [
        {"role": "system", "content": PROMPT_CV},
        {"role": "user", "content": texte or ""},
    ]


async def analyser_cv(
    *,
    texte: str | None = None,
    image: bytes | None = None,
    type_image: str | None = None,
    appeler: Appelant,
) -> tuple[dict[str, Any], str, CoutAppel]:
    """Rend le profil structuré, la transcription, et le coût de l'appel.

    `appeler` est injecté : un test unitaire ne doit pas sortir sur le réseau.
    Une seule relance en cas de lecture impossible (§9) — pas zéro, pas trois :
    chaque relance est un appel payé.
    """
    messages = _messages(texte, image, type_image)
    derniere_erreur: CvIllisible | None = None

    for tentative in (1, 2):
        contenu, cout = await appeler(messages)
        try:
            profil = _valider(json.loads(_nettoyer(contenu)))
        except (json.JSONDecodeError, CvIllisible) as exc:
            # Aucun extrait de la réponse dans le journal : elle contient le CV.
            log.warning(
                "cv_reponse_illisible",
                tentative=tentative,
                type_erreur=type(exc).__name__,
                version_prompt=VERSION_PROMPT_CV,
            )
            derniere_erreur = CvIllisible()
            continue
        transcription = str(profil.pop("transcription"))
        return profil, transcription, cout

    raise derniere_erreur or CvIllisible
```

"""Profil : dépôt du CV, consultation, correction (spec §7).

Tout ce qui peut être refusé l'est **dans la requête**, avant qu'un seul token
soit payé : taille, type réel, plafond du jour, absence de texte. L'analyse
elle-même part en arrière-plan et la route rend la main tout de suite —
l'utilisateur est sur une 3G comptée, il ne doit jamais attendre un appel LLM.
"""

from __future__ import annotations

import asyncio
from datetime import UTC, datetime
from typing import Annotated, Any

import redis.asyncio as aioredis
from fastapi import APIRouter, Depends, File, Response, UploadFile, status
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from src.api import deps
from src.api.schemas.profil import CorrectionProfil, ProfilVu
from src.config import Settings, get_settings
from src.core import cv_fichier
from src.core.auth import cles
from src.core.cv_etat import etat_affiche
from src.core.cv_limites import autoriser_analyse_cv

from src.db.models import Profile, User
from src.db.session import session_scope
from src.llm.client import appeler_deepseek

from src.logging_setup import get_logger

# `asyncio` ne retient qu'une référence FAIBLE vers une tâche : sans cet
# ensemble, le ramasse-miettes peut emporter l'analyse en plein vol.
_TACHES_DE_FOND: set[asyncio.Task[None]] = set()

_PREFIXE_IMAGE = "jobbot:cv:image"


def _vue(profil: Profile | None) -> ProfilVu:
    if profil is None:
        return ProfilVu(etat="absent")
    return ProfilVu(
        etat=profil.parse_etat, erreur=profil.parse_erreur, structured=profil.structured
    )


async def _profil_de(session: AsyncSession, user_id: int) -> Profile | None:
    return (
        await session.execute(select(Profile).where(Profile.user_id == user_id))
    ).scalar_one_or_none()


@router.get("/profil")
async def voir_profil(
    utilisateur: Annotated[User, Depends(deps.utilisateur_courant)],
    session: Annotated[AsyncSession, Depends(deps.session_db)],
    settings: Annotated[Settings, Depends(deps.reglages)],
) -> ProfilVu:
    """Une analyse `en_cours` depuis trop longtemps est présentée comme échouée.

    C'est ce qui remplace un balayeur de tâches zombies : si `api` redémarre en
    pleine analyse, rien ne reprend le travail, et l'écran le dit au lieu de
    faire tourner l'utilisateur dans une attente sans fin (spec §6).
    """
    profil = await _profil_de(session, utilisateur.id)
    if profil is None:
        return ProfilVu(etat="absent")
    etat, erreur = etat_affiche(
        profil.parse_etat,
        profil.parse_demarre_le,
        maintenant=datetime.now(UTC),
        delai_max_secondes=settings.cv_analyse_delai_max_secondes,
    )
    return ProfilVu(etat=etat, erreur=erreur or profil.parse_erreur, structured=profil.structured)


async def _analyser_en_arriere_plan(
    user_id: int, texte: str | None, cle_image: str | None, type_image: str | None
) -> None:
    """Possède son propre client Redis et sa propre session.

    Le client de `deps.cache_redis` est fermé en fin de requête : le passer ici
    laisserait la tâche travailler sur une connexion morte — piège déjà payé en
    Phase 2 sur le rafraîchissement des offres.
    """
    settings = get_settings()
    client: aioredis.Redis = aioredis.from_url(settings.redis_url, decode_responses=False)
    try:
        image: bytes | None = None
        if cle_image is not None:
            image = await client.get(cle_image)
            await client.delete(cle_image)
            if image is None:
                # Le TTL a expiré avant qu'on consomme l'image. Pas de reprise à
                # écrire : l'utilisateur redépose.
                await _marquer_echec(user_id, "image_expiree")
                return

        profil, transcription, cout = await analyser_cv(
            texte=texte,
            image=image,
            type_image=type_image,
            appeler=lambda messages: appeler_deepseek(
                messages,
                modele=settings.deepseek_modele,
                cle_api=settings.deepseek_api_key.get_secret_value(),
                temperature=0.3,
            ),
        )
    except Exception as exc:  # noqa: BLE001 — une analyse ratée n'est pas une panne
        # Seul le NOM du type : le message d'une exception de cette chaîne peut
        # contenir un fragment de CV, et une alerte admin recopie son contexte
        # par le réseau (§7).
        code = getattr(exc, "code", None) or "analyse_echouee"
        log.error("cv_analyse_echouee", user_id=user_id, type_erreur=type(exc).__name__)
        await _marquer_echec(user_id, str(code))
        return
    finally:
        await client.aclose()

    async with session_scope() as session:
        ligne = await _profil_de(session, user_id)
        if ligne is None:  # compte supprimé pendant l'analyse
            return
        ligne.raw_cv_text = transcription
        ligne.structured = profil
        ligne.parse_etat = "pret"
        ligne.parse_erreur = None
    log.info(
        "cv_analyse_terminee",
        user_id=user_id,
        tokens_entree=cout.tokens_entree_frais + cout.tokens_entree_cache,
        tokens_sortie=cout.tokens_sortie,
        cout_usd=str(cout.cout_usd),
    )


async def _marquer_echec(user_id: int, code: str) -> None:
    async with session_scope() as session:
        ligne = await _profil_de(session, user_id)
        if ligne is not None:
            ligne.parse_etat = "echec"
            ligne.parse_erreur = code


def _planifier(coro: Any) -> None:
    tache = asyncio.create_task(coro)
    _TACHES_DE_FOND.add(tache)
    tache.add_done_callback(_TACHES_DE_FOND.discard)


@router.post("/profil/cv", status_code=status.HTTP_202_ACCEPTED)
async def deposer_cv(
    response: Response,
    utilisateur: Annotated[User, Depends(deps.utilisateur_courant)],
    session: Annotated[AsyncSession, Depends(deps.session_db)],
    cache: Annotated[Any, Depends(deps.cache_redis)],
    settings: Annotated[Settings, Depends(deps.reglages)],
    fichier: Annotated[UploadFile, File()],
) -> ProfilVu:
    contenu = await fichier.read()
    if len(contenu) > settings.cv_taille_max_octets:
        raise CvTropGros

    type_cv = cv_fichier.reconnaitre_type(contenu)

    # Le plafond est consommé AVANT tout travail : extraire le texte puis
    # refuser serait du calcul payé pour rien.
    await autoriser_analyse_cv(
        cache,
        user_id=utilisateur.id,
        par_jour=settings.cv_analyses_par_jour,
        secret=cles.deriver(settings.jwt_secret.get_secret_value(), "limite"),
    )

    texte: str | None = None
    cle_image: str | None = None
    if cv_fichier.est_une_image(type_cv):
        # Une photo n'a pas de texte à extraire : elle doit survivre jusqu'à la
        # tâche de fond. Redis avec un TTL court — jamais le disque, jamais
        # Postgres, donc jamais une sauvegarde (spec §8).
        cle_image = f"{_PREFIXE_IMAGE}:{utilisateur.id}:{datetime.now(UTC).timestamp()}"
        await cache.set(cle_image, contenu, ex=settings.cv_image_ttl_secondes)
    else:
        texte = cv_fichier.extraire_texte(
            contenu, type_cv, minimum=settings.cv_texte_min_caracteres
        )

    profil = await _profil_de(session, utilisateur.id)
    if profil is None:
        profil = Profile(user_id=utilisateur.id)
        session.add(profil)
    profil.parse_etat = "en_cours"
    profil.parse_erreur = None
    profil.parse_demarre_le = datetime.now(UTC)
    await session.flush()

    _planifier(
        _analyser_en_arriere_plan(utilisateur.id, texte, cle_image, type_cv)
    )
    return _vue(profil)


@router.put("/profil")
async def corriger_profil(
    corps: CorrectionProfil,
    utilisateur: Annotated[User, Depends(deps.utilisateur_courant)],
    session: Annotated[AsyncSession, Depends(deps.session_db)],
) -> ProfilVu:
    """Corrections et préférences dans la même soumission : chaque étape coûte
    des abandons et un aller-retour payé en data (§11)."""
    profil = await _profil_de(session, utilisateur.id)
    if profil is None or profil.structured is None:
        raise ProfilAbsent

    structure = dict(profil.structured)
    for champ, valeur in corps.model_dump().items():
        structure[champ] = valeur
    profil.structured = structure
    return _vue(profil)

export async function profil(): Promise<Profil | null> {
  try {
    return (await (await appeler('/profil')).json()) as Profil
  } catch (erreur) {
    if (erreur instanceof ErreurApi && erreur.statut === 401) return null
    throw erreur

export async function deposerCv(fichier: File): Promise<Profil> {
  const corps = new FormData()
  corps.append('fichier', fichier)
  // Pas de Content-Type manuel : le FormData pose sa propre frontière multipart.
  const reponse = await appeler('/profil/cv', { method: 'POST', body: corps })
  return (await reponse.json()) as Profil
}

export async function corrigerProfil(donnees: Record<string, unknown>): Promise<Profil> {
  const reponse = await appeler('/profil', {
    method: 'PUT',
    body: JSON.stringify(donnees),
    headers: { 'Content-Type': 'application/json' },
  })
  return (await reponse.json()) as Profil
}

```ts
'use server'

import { redirect } from 'next/navigation'

import { ErreurApi } from '../api-contrat'
import { corrigerProfil, deposerCv } from '../api-client'
import { journaliser } from '../journal'

export async function envoyerCv(formData: FormData): Promise<void> {
  const fichier = formData.get('fichier')
  if (!(fichier instanceof File) || fichier.size === 0) {
    redirect('/profil?erreur=cv_type_refuse')
  }

  // redirect() lève une exception interceptée par Next : jamais dans un try.
  let echec: string | null = null
  try {
    await deposerCv(fichier)
  } catch (erreur) {
    if (erreur instanceof ErreurApi) echec = erreur.code
    else throw erreur
  }

  if (echec) {
    journaliser('cv_refuse', { code: echec })
    redirect(`/profil?erreur=${encodeURIComponent(echec)}`)
  }
  journaliser('cv_depose')
  redirect('/profil')
}

export async function enregistrerProfil(formData: FormData): Promise<void> {
  const liste = (cle: string): string[] =>
    String(formData.get(cle) ?? '')
      .split(',')
      .map((v) => v.trim())
      .filter(Boolean)

  const donnees = {
    nom_complet: String(formData.get('nom_complet') ?? '').trim() || null,
    titre: String(formData.get('titre') ?? '').trim() || null,
    competences: liste('competences'),
    langues: liste('langues'),
    secteurs_vises: formData.getAll('secteurs').map(String),
    mobilite: String(formData.get('region') ?? '').trim() || null,
    type_contrat: String(formData.get('contrat') ?? '').trim() || null,
  }

  let echec: string | null = null
  try {
    await corrigerProfil(donnees)
  } catch (erreur) {
    if (erreur instanceof ErreurApi) echec = erreur.code
    else throw erreur
  }

  if (echec) redirect(`/profil?erreur=${encodeURIComponent(echec)}`)
  journaliser('profil_valide')
  redirect('/offres')
}
```
